## 🏎️ F1 Race Analysis Dashboard

> A Machine Learning and Data Analytics dashboard for analysing Formula 1 race performance.

### ✨ What it does

* 🏁 Predicts race winners using XGBoost
* 📈 Compares qualifying and race performance
* 🚀 Identifies biggest position gainers and fallers
* 🤝 Compares teammate performance
* 🧘 Finds the most consistent drivers
* ⚡ Identifies the best race starters
* ⏱️ Analyses tyre degradation using Linear Regression
